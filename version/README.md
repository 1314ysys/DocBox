# version/ — 版本基线目录

每次发布基线都在这里留一份不可变记录，便于回溯“某版本交付了什么”。

- `<version>/VERSION.json`：机器可读的版本元数据（版本号、发布时间、工具数量、能力摘要、已知问题、验证结论）。
- `<version>/CHANGELOG.md`：人类可读的变更说明（新增 / 变更 / 移除 / 修复 / 已知问题 / 验证）。
- 对应 git tag：`<version>`（本次为 `v0.1.2`）。
