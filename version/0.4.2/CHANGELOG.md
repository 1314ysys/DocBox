# DocBox 0.4.2

> 主题：水印模板对齐参考样式（通用品牌 / 考勤打卡 / 工程记录 / 自定义水印），图片编辑可以自由选区与缩放。

## 1. 图片水印：按参考图新增 4 套模板（共 11 套）

字段严格按参考截图来（真实时间 / 地点 / 经纬度 / 海拔 / 天气 / 方位角 / 拍摄人 / 工作单位 / 备注）：

| 模板 id | 名称 | 布局 |
| --- | --- | --- |
| `brand` | 通用品牌 | 品牌名 → 真实时间 → 地点 → 经纬度/天气/海拔/方位角 → 拍摄人 → 工作单位 → 备注 |
| `attendance` | 考勤打卡 | 公司/品牌 → 大字打卡时间 → 日期星期天气 → 地点 → 经纬度/海拔 → 拍摄人 → 工作单位 → 备注 |
| `record` | 工程记录 | 自定义标题 → 施工内容 → 拍摄时间 → 地点 → 经纬度/天气/海拔/方位角 → 拍摄人 → 工作单位 → 备注 |
| `custom` | 自定义水印 | 自定义标题 → 自定义多行文字 → 拍摄时间 → 地点 → 经纬度/天气/海拔/方位角 → 拍摄人 → 工作单位 → 备注 |

配套改动：

- `src/watermark-templates.mjs`：新增 `refGeo` 字段组（海拔 `elevation`、方位角 `bearing`、拍摄人 `photographer`、工作单位 `company`），4 套新模板排在最前面；
- `src/lib/watermark.mjs`：新增两种行类型
  - `facts`：把多个「标签：值」拼成一行（例：`经纬度：26.8°N · 天气：晴 · 海拔：301.4`）；
  - `free`：自定义多行文字，每行一条；
- `src/lib/watermark.mjs` 增加**文字溢出兜底**：原按字宽估算换行，遇到数字/度分秒串会算窄导致 `Image to composite must have same dimensions or smaller`；现在超宽行与超宽标注值会自动等比缩到卡内，并在合成前再兜一层。

## 2. 图片编辑：修好「不能自由选区」，并支持缩放

问题根因：画布按缩小后的尺寸绘制，而选区框是相对 `.canvas-wrap` 绝对定位的，坐标来自 canvas 的 `offsetX`，两者基准不同 → 拖出来的框和鼠标对不上；且画布固定缩放到窗口，放大不了看不清细节。

修复与增强：

- 画布改为**原图 1:1 绘制**，缩放只改 CSS 尺寸 → 选区坐标 ≡ 原图坐标，裁剪精度不受显示大小影响；
- 新增 `#edStage` 定位容器包住画布与选区框，框坐标随缩放同步换算；
- **右键拖拽**划选区（左键不再误触发，`contextmenu` 已屏蔽，触屏/手写笔仍可用左键拖）；松开时显示「选区 W × H px」；
- **滚轮**以光标为中心自由缩放（20%~1200%），**中键拖拽**平移（`pointerdown button=1` 改 `scrollLeft/Top`）；
- 工具栏新增 `−` / 缩放百分比（点一下回「适应」）/ `＋`，并加了操作提示「右键拖拽选区 · 滚轮缩放 · 中键拖拽平移」；
- 变换（旋转/翻转/裁剪/改尺寸）后自动回到「适应」，其余情况保留当前缩放。
